# Runbook Directory Layout

Runbooks are grouped by area so you can jump directly to the workflows you need:

- `010-foundation` – environment and makefile quickstarts.
- `020-fhir` – FHIR profiles and validation quickstart.
- `030-mapping-and-terminology` – mapping evaluation, terminology APIs, vector store quickstarts.
- `040-warehouse-and-bi` – warehouse loading and BI integration quickstarts.
- `050-web-app` – web app quickstart.
